## ⚙️ 工作原理

1. **每小时自动运行** GitHub Actions
2. **爬取三家平台** 北京朝阳区的外卖数据
3. **智能匹配** 同一商品/相似商品
4. **计算总价** 商品价格 + 配送费
5. **生成报告** Markdown 表格展示

## 💡 使用提示

- 🟡 **美团**: 商家最多，配送快，价格中等
- 🔵 **饿了么**: 优惠多，价格较低，补贴力度大
- 🔴 **京东到家**: 配送稳定，但价格通常较高

**省钱技巧**:
1. 对比三家平台价格
2. 注意配送费（有些免配送费）
3. 关注满减活动
4. 新用户有首单优惠
